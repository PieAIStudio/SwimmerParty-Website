# Setting references

One renderer-independent picker, shared by Guide and the scene panel. Six cards: studio, café, street, garden, living room and gym. Pick a card to edit its own sentence, copy that sentence as a prompt, or save its reference image when supplied. No model calls, uploads, provider options or generated-output claims.

- `index.ts` exports `SettingCards`; `contracts.ts` is the pure public draft schema. Neither imports scene or Three. Guide keeps edits in page memory; scene stores the selected ID and all sentence edits in its existing local draft/history. Older version-1 scene drafts default this additive field safely.
- `src/content/settings.ts` is the image manifest and ID source. All six `image` slots are currently **null**: visible pending labels, no image requests, disabled Save image. A placeholder is not a downloadable setting reference. UI labels/default sentences belong only to `src/i18n/messages.source.ts`.
- When MediaFactory supplies cleared originals, record provenance/licence with the delivery, review the real images, then fill `preview`, `download`, `filename`, `width` and `height` in the manifest. Use an approved local/owned image path; keep the original format's filename. The shared `fetchImageBlob` validates the MIME/body and `saveBlob` downloads the actual file. Preview images load lazily. No renderer change or fake test-image substitution is needed.
- SSR renders the new sentence/choice controls disabled until React hydrates them. Use the server/client `useSyncExternalStore` snapshot, not an effect-driven setState or a lint exemption. Pixel review caught mixed initial/edited text on a fast load; the blocked-JS regression now proves edits cannot start before handlers are ready.
- The editable sentence remains selectable if clipboard access is denied. Copy reuses the existing site `CopyButton`, not a parallel clipboard implementation. Settings are references, never painted into the 3D canvas or PNG.

The existing push selector adds changed-source format/lint/types and paired-message checks; browser mapping is explicit, not inferred from application imports. Clipboard APIs are isolated in-page fakes so acceptance never changes the Owner's OS pasteboard. No real reference-image download can be accepted until actual files arrive. Physical phones, Safari and external image-tool fidelity remain untested. Unchanged renderer/asset/performance evidence is retained from the scene slice; no entire browser/timing suite is required for these cards.
