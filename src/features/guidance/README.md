# First-use guidance

产品只拥有四个首次操作时机和已读偏好；外观、交互、视频生命周期、Esc 与触屏由现装 UIKit GameHelpCard/GameButton 拥有，不另造提示组件。

- 成功下载/加入选角、主动打开投稿器/成功投票发送本地 `sp-first-use`。不在访问页面时自动弹窗、不连接分析服务，也不借事件触发投稿或生成。
- 首次只出现一个可选帮助入口，不抢焦点。打开或明确关闭后记录 `sp-first-use-v1:<kind>=seen`；未读排队项不提前消费。换页清瞬态队列；localStorage 不可用只在当前页面会话记住，不能声称跨刷新持久。
- 账号/署名条件始终在真实操作旁；社区上传尚未接入，不在提示中复制 v3 额度，更不以说明冒充已支持上传。
- 演示直接复用 `public/help` 既有片段。手动演员页问号始终可用，不因第一次提示已读而消失。
- 纯合同测试在 `tools/test/guidance.test.ts`，实际触屏/键盘/已读/排队及下载进度由 `e2e/guidance-next-stage.spec.ts` 验证；四事件呈现测试不代表社区后端已验收。
