# Scene

Optional local blocking tool at `/[locale]/scene`, reached from Your cast. It does not change actor data or download/account rules. Generic stand-ins are explicitly not delivered actor models. No generation, uploads, cloud saves, animation player or joint editor.

- `index.ts` is the server page entry; `SceneEditor` owns plain versioned draft/history and UIKit controls. Only its `dynamic(..., {ssr:false})` canvas imports Three/Fiber/Drei. Cast links disable prefetch. Do not export the canvas through a shared site/client barrel.
- `model.ts` owns limits, six pose/build/view IDs, camera fitting and local draft validation. Heights are centimetres; ground x/z are metres, Y is elevation, +Z is forward. Missing actor height starts at an explicitly approximate 175 cm. Body width changes use distinct prepared assets, not a whole-body horizontal stretch.
- The WebGL surface has a fixed neutral export palette, independent of the UI theme. Preview and PNG share the camera, aspect, attached number markers and coloured floor bands. A readable name/colour key sits below the preview; PNG composites a numbered actor-name key along its bottom edge so names cannot occlude one another in face-off views. Colours identify slots in this draft, not actor brands. Copy prompt maps those same labels/colours to each actor's reference-sheet page; unassigned figures are explicitly marked. Demand rendering, DPR capped at 1.5; no post-processing or remote lighting. Export renders at the requested dimensions, omits grid/selection and restores preview sizing in `finally`.
- `sp-scene-v1` saves one local draft; Undo/Redo is session-only (30 edits). More than five requested actors opens an explicit chooser without mutating the saved cast. Storage/WebGL failure leaves ordinary actor references and the Guide available.
- Setting references reuse `features/settings`, also used in Guide. Selected setting/sentence edits share this draft/history; old drafts receive defaults. References are not 3D backgrounds and never change the clean PNG. Image slots stay honestly empty until real MediaFactory references arrive; ownership and bounded integration checks are in `../settings/README.md`.

## Figure asset handoff

`loadFigure(build, pose) → GLB URL` in `figure-assets.ts` is the sole runtime seam. `figures.json` owns the asset base and exact standing bounds per build. Only a figure's current URL is loaded; identical URLs share the loader cache. Stand uses the root default; other poses use `poses/<build>-<pose>.glb`. No family preload. The 21 original delivery files are retained, including the three duplicate stand variants.

MediaFactory's `handoff-mannequin` (2026-11-05, `windows-tuning-20261105`) supplies slim/average/broad builds and stand/walk/point/wave/sit/arms-crossed static meshes. Each GLB is **7,478 triangles**, one mesh/material, no textures, skins or animation clips. Metres, +Y up, +Z forward, floor origin. `figureScale` divides requested stature by the recorded standing Y bound (1.7225 / 1.752 / 1.7916 m); seated/walking poses use that same standing denominator, never a horizontal stretch. Cloned nodes keep transforms independent while geometry/materials stay shared. Old v1 draft build/pose IDs migrate to the nearest available preset.

The delivered [LICENSE.md](../../../public/scene/figures/LICENSE.md) and [producer manifest](../../../public/scene/figures/manifest.json) are copied unchanged. All 21 GLB SHA-256/byte counts and the licence hash were checked before import. Producer `deliver/` paths are provenance keys; `consumerMappingSuggestion.byBuildRelativeToManifest` is relative to the delivered folder. The licence records MPFB 2.0.18, donor commit, package hash, CC0 asset-data provenance and excluded GPL add-on code; this README adds no broader licence claim. No actor likeness/model, Mannequin.js or GPL application code is shipped. Keep the **10,000-triangle** ceiling and record exact provenance with future replacements; the renderer licence does not clear a model.
