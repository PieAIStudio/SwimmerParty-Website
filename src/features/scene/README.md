# Scene

Optional local blocking tool at `/[locale]/scene`, reached from Your cast. It does not change actor data or download/account rules. Generic stand-ins are explicitly not delivered actor models. No generation, uploads, cloud saves, animation player or joint editor.

- `index.ts` is the server page entry; `SceneEditor` owns plain versioned draft/history and UIKit controls. Only its `dynamic(..., {ssr:false})` canvas imports Three/Fiber/Drei. Cast links disable prefetch. Do not export the canvas through a shared site/client barrel.
- `model.ts` owns pose/build IDs, ready layouts, framing requests and local draft validation. Lazy `framing.ts` measures the loaded, scaled and turned posed meshes, then uses CameraControls' distance solver on camera-oriented bounds (its `fitToBox` snaps to cardinal axes in 3.1.2). Full includes the raised hands and number; Medium/Close-up crop the actual posed upper body. Heights are centimetres; ground x/z are metres, Y is elevation, +Z is forward. Missing actor height starts at an explicitly approximate 175 cm. Body width changes use distinct prepared assets, not a whole-body horizontal stretch.
- The WebGL surface has a fixed neutral export palette, independent of the UI theme. Preview and PNG share the CameraControls camera, aspect, attached number markers and coloured floor bands. Number badges remain readable at phone preview sizes. Shot (Full/Medium/Close-up), angle (Eye/Low/High/1→2 shoulder), 24/50/85 mm lens and subject (selected figure/everyone) are independent controls. The shoulder view uses figure 1 as foreground and frames figure 2; choosing everyone or another subject returns to Eye. The fixed horizontal sensor gate is 36 mm. A readable name/colour key sits below the preview; PNG appends a fixed-size, wrapping numbered actor-name key below the camera image so names cannot occlude figures or shrink with cast size; a caption records lens, shot, angle and subject. FRAMES dimensions describe the camera image; the key adds 64 px per row plus a 48 px caption below it. Save scene downloads the same v1 JSON as the local draft, including camera position/target/lens/shot/sensor/subject; this is not yet the shared MediaFactory rig/pose interchange. Colours identify slots in this draft, not actor brands. Copy prompt maps those same labels/colours to each actor's reference-sheet page; unassigned figures are explicitly marked. Demand rendering, DPR capped at 1.5; no post-processing or remote lighting. Export renders at the requested dimensions, omits grid/selection and restores preview sizing in `finally`.
- `sp-scene-v1` saves one local draft (old camera fields receive defaults); Undo/Redo is session-only (30 edits). Automatic fit resolution replaces the pending camera within the same history entry; orbit/pan/zoom gestures are saved as edits. All requested actors enter directly without mutating the saved cast. There is no people cap; numbered identities remain unique when the eight band colours repeat. Ready layouts place 2/3/5/8 grounded figures; layouts reuse the first assigned actors and undo restores the previous group. Storage/WebGL failure leaves ordinary actor references and the Guide available.
- Setting references reuse `features/settings`, also used in Guide. Selected setting/sentence edits share this draft/history; old drafts receive defaults. References are not 3D backgrounds and never change the clean PNG. Delivered MediaFactory references support real PNG downloads; any future undelivered slot stays honestly empty. Ownership, grouped browsing and bounded integration checks are in `../settings/README.md`.

## Figure asset handoff

`loadFigure(build) → GLB URL` and `loadPose(pose) → JSON URL` in `figure-assets.ts` are the runtime seam. Only the lazy canvas requests the current bodies and poses; identical URLs share the loader cache, and changing a pose reuses the body GLB. `figures.json` records the six standing skinned heights, measured with the delivered stand pose. Actor gender selects the matching average body; an explicit known build can refine it, and missing information uses average. The website actor contract currently supplies gender and stature, not a build classification; no build is inferred from appearance.

MediaFactory commit `54a0566ce7958cffc637bb421be159195107c3ee`, `handoff-rigged/`, supplies slim/average/broad and their `-f` variants plus twelve shared poses. Each body has one skinned mesh, the same 53 named bones, no textures or animation clips, and 7,478 male / 8,022 female triangles. Metres, +Y up, +Z forward. `rigged-figure.ts` uses SkeletonUtils.clone for independent skeletons, applies every local quaternion by bone name, updates skin bounds, and grounds the actual deformed vertices at y=0 after stature scaling. The loader source remains untouched. Pose changes and body swaps preserve the saved pose; old v1 draft IDs still migrate. Sitting adds one neutral grey stool under the posed pelvis, moving/scaling/turning with that figure and included in bounds and PNGs; no table or other prop is added. Preview culling and framing use refreshed deformed bounds. Static posed vertices are baked once into a CPU-only picking mesh, so pointer moves use accurate triangles without repeating bone transforms per triangle; hits retain the original skinned mesh identity, and the cache follows placement/turning and is disposed with that pose.

The delivered [LICENSE.md](../../../public/scene/rigged/LICENSE.md), [producer manifest](../../../public/scene/rigged/manifest.json) and [apply-pose README](../../../public/scene/rigged/README.md) are copied unchanged beside the six GLBs and twelve pose JSONs. Every delivered body/pose SHA-256 and byte count is checked against that manifest, with metadata pinned in the acceptance test. The licence records MPFB 2.0.18, donor commit/package hash and CC0 asset-data provenance, excluding GPL add-on code; this README adds no broader licence claim. No actor likeness/model, Mannequin.js or GPL application code is shipped. The previous static delivery remains archived at `public/scene/figures/` for provenance and is never requested by the stage. Keep the **10,000-triangle** ceiling; the renderer licence does not clear a model.
