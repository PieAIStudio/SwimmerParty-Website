## 2. 可点元素的规则（全站统一）

### 2.1 规则

写进 `DESIGN.md` 的新小节"可点的东西长什么样"，全站照做：

1. **主按钮**：液体胶囊，每屏最多一个，用于这一屏最重要的一步。
2. **按钮**：有底的胶囊或圆形图标，用于"在这一页做一件事"，例如下载、选中、复制、登录、切换语言或明暗、打开菜单。
3. **链接**：文字加 `→`，用于"去另一页"。
   - 一律用前景色、半粗，悬停加下划线；
   - "上一级"用面包屑，不用 `←` 链接。
4. **卡片**：整张可点，例如演员卡、作品卡、出演卡。
   - 悬停时图片放大 1.02、标题加下划线（沿用现有效果）；
   - 卡片里不再放第二个链接。
5. **单独陈列的图片**：点了看大图（第 3 节），鼠标显示放大镜光标。卡片里的图属于卡片，点了去卡片的目的地。
6. **导航区**：页头、面包屑、页脚按惯例用文字，不加箭头。
7. **正文区的灰色文字一律不可点。** 现在有些链接是灰色（如首页"找我们合作"），全部改成前景色。

不给所有链接加底：全都有底，主按钮就不突出了，页面会像控制面板。箭头链接是 Apple、Stripe 等网站通用的写法。
这套规则用现有 UIKit 组件和本站 `TextLink` 就能实现，**这一轮不改 UIKit**。

### 2.2 同一个地方只有一个入口、一个叫法

- 同一屏（同一区块）里，同一个目的地只出现一次。
- 首页是导览页，每个区块末尾可以有一个"去看详情"的链接，但同一区块内不重复。
- 同一个目的地全站用同一个叫法。只有主按钮可以用行动式说法，例如"免费领取演员资产"。

| 目的地                  | 中文         | English            |

## 3. 看大图（灯箱）

### 3.1 用开源组件

用 **`yet-another-react-lightbox`**（MIT），按精确版本安装（2026-10-07 最新 3.32.2）。只用 Zoom 和 Counter 两个插件。

| 选项                       | 结论                                                                                                        |
| -------------------------- | ----------------------------------------------------------------------------------------------------------- |
| yet-another-react-lightbox | 采用：React 组件，2026-07 仍在更新，支持 React 19；自带缩放、手势、键盘、焦点管理；按钮和样式都能换成我们的 |
| PhotoSwipe 5               | 不选：最后一次发布在 2024-05，React 要另包一层                                                              |
| 自己写                     | 不选：缩放、双指、滑动、焦点、预加载都要自己处理，容易出错                                                  |

**按需加载**：灯箱的代码和 CSS 在第一次打开时才加载。鼠标悬停、获得焦点或手指按下时可以提前加载。
演员页和资产库页的首屏 JS 不能因此变大（见第 11 节）。

### 3.2 统一的操作方式（全站一样）

- **点图 = 看大图**：参考图组、演员页主图、资产库的每一格、作品页的剧照都是这样。
- **点左上角的勾选框 = 选中**：只有资产库有这个框。
  - 勾选框的点击区域扩大到至少 44×44；
  - 不论有没有选中图片，"点图"都只打开大图，没有"选择模式"切换。
- **点右上角的下载 = 下载这一张**：只有资产库有，规则不变（游客 30 秒一张）。
- 在大图里可以继续选中或取消、下载，所以边看边选不用退出。
- 键盘：图片、勾选框、下载按钮各自能用 Tab 聚焦；在图片上按回车打开大图。

`AssetTile` 现在整格是"选中"按钮，要改成：整格是"查看大图：{名称}"按钮，选中只靠勾选框。相应改 e2e。

### 3.3 大图的样子和行为

- **外观**：
  - 背景用当前主题的页面底色，不透明度约 95%，不加模糊（`DESIGN.md` 只允许页头模糊）；
  - 图片放在和资产格一样的 `sp-sweep` 摄影棚底上，透明图不能直接浮在纯色上；
  - 按钮全部用 UIKit `GameIconButton`：关闭在右上；桌面在左右两侧放上一张、下一张，触屏靠滑动；
  - 底部用 `sp-small` 显示名称和"3 / 63"。
- **资产库专属**：工具条上有"选中"勾选框和"下载这一张"，状态和格子里的同步。
- **翻页**：左右方向键、滑动、按钮都能翻页；不循环；同组内连续翻，资产库按页面顺序跨系列翻。
- **缩放**：双击、双指、滚轮都能缩放，最大到原图像素（`maxZoomPixelRatio` 为 1），不放大到发糊。
- **关闭**：Esc、关闭按钮、点空白处、手机向下拉都能关闭；关闭后焦点回到打开它的那张图。
- **手机返回键**：打开大图时加一条浏览记录，按返回键只关闭大图，不离开页面。
- **减少动态**：开启"减少动态"时，打开和翻页没有动画。
- **文案**：所有按钮名称走 i18n。
- **清晰度**（Owner 决定 A）：
  - 入库工具为每张图多生成一份原尺寸 webp：`<slot>.large.webp`，941×1672，质量约 82，只在大图里用；
  - 大图同时给 `srcSet`：先显示 576 宽的预览，再换成原尺寸；
  - 两位现役演员的 126 张从 `media-pack/library/staging/` 重新生成，生成前核对源文件的 sha256 和清单一致；
  - 透明 PNG 原图的下载规则不变；
  - 报告里写清新增文件占多少空间。

## 6. 版本号

### 6.1 三段数字的意思

格式 `大.小.修`，例如 `1.0.0`：

- **大版本**：形象换了，脸、身材或锚点图重做，旧图和新图不再是同一套。
  大版本必须等于项目包 `cast/<code>.json` 的 `anchorVersion`，也等于文件名里的 `v1`。
- **小版本**：加了内容，旧图仍然有效。例如新造型、新系列、新角度，或者声音、视频上线。
- **修正版本**：修了问题。例如重画一张有瑕疵的图、修透明边或裁切、改错字。

### 6.2 数据

- **唯一来源**：`src/content/actors/<slug>/releases.ts`，按新到旧排列，每条有版本号、日期和双语说明。第一条就是当前版本。
- 两位现役演员的第一条都是 `1.0.0 · 2026-10-05`，说明写"首次发布：共 63 张"，按系列列出张数。上线前的试做不算版本。
- 还没发布过的演员没有这个文件，页面上不显示版本。

### 6.3 显示和下载

| 位置             | 显示                                            |
| ---------------- | ----------------------------------------------- |
| 演员页           | 当前版本号和日期（资料表里的一行）              |
| 资产库页头       | `v1.0.0`                                        |
| 资产库"版本记录" | 全部历史                                        |
| JSON 资料        | 加 `version` 字段                               |
| ZIP 文件名       | 带版本，例如 `SP-13_v1.0.0_assets_20261007.zip` |

### 6.4 检查和流程

- **工具测试**：
  - 版本号格式正确，按新到旧排列，日期有效；
  - 大版本等于 `assets.json` 里图片的最大 `version`；
  - 有交付图片的演员必须有 `releases.ts`。
- **入库流程**：在 `release.md` 的入库步骤和 `architecture.md` 的"常见改动"里加一条：每次加图或改图都要加一条版本记录，按 6.1 决定升哪一位。

## 9. "资料"那排胶囊为什么不对

演员页"资料"用的是 UIKit 的 `GameFactList`。它是给游戏画面做的悬浮信息条：深色玻璃底、细描边、全圆角，所以质感和圆角都和网站卡片不同。

本站还给"图片"那项传了 `tone`。组件会把值再渲染成一个徽章，于是"打开 63 张图片"出现了两次。

**这不是 UIKit 的问题，UIKit 也没有更新的版本**：2026-10-07 `next` 仍是本站在用的 3.0.0-rc.1。问题在我们用错了组件。

第 4、5 节已经把这块改成资料表的一行和资产库页头的 `GameBadge`。全站不再使用 `GameFactList`，并在 `DESIGN.md` 里写明：网站不用 `game/` 类组件。
