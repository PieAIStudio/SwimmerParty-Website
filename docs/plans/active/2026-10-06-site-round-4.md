# 网站第四轮：分享卡片露脸、档案页提速、安全检查

**先做完第三轮**（`2026-10-06-site-round-3.md` 第 6 节）再开始这一轮；第三轮的部署 ID 记在 `.devspace-reports/site-round-3/REPORT.md`。
网站在试运营，没有真实用户。这一轮做三件 Owner 不用插手的改进，做完直接发布。

- 联系邮箱现在是 Owner 的个人邮箱 `pieai@hotmail.com`，这是 Owner 定的，**这一轮不动**。品牌邮箱要等下次改版加演员时再弄。

## 1. 分享卡片露出演员的脸

现在演员页、资产库页和首页的分享卡片，都只有深色底加文字。选角网站的链接被转发到 X、Slack、Discord、Telegram 时，最该被看到的是演员本人。

- **结果**：
  - 转发演员页或资产库页，卡片上能看到这位演员的样子和名字；
  - 转发首页，卡片上能看到现役演员；
  - 中英文两个版本都要对。
- **约束**：
  - 卡片仍是 1200×630 PNG，沿用现有的卡片路由；
  - `next/og` 读不了 webp，而网站的公开图都是 webp，所以要先转成 png 或 jpeg。在哪一步转由你决定（入库时生成，或卡片路由里转）；
  - 中文名必须显示成字，不能是方框或空白；
  - 卡片的视觉语言跟网站一致（颜色、字体气质看 `DESIGN.md`）；
  - 新演员入库后，卡片要自动有脸，不需要手工补图。
- **验收**：
  - 两位现役演员 × 中英文 × 演员页和资产库页，共 8 张卡片，加上中英文首页 2 张，在本地截图放进报告；
  - 发布后在正式站抽查其中 3 张，返回 `200 image/png`，并且和本地截图一致。

## 2. 档案页和资产库页的手机速度

第三轮只优化了首页。第二轮正式站的手机端 Lighthouse 结果：

| 页面                            | 速度指数 | 最大内容绘制 |
| ------------------------------- | -------- | ------------ |
| 首页 `/en`                      | 7.4 秒   | 2.1 秒       |
| 档案页 `/en/actors/tang-yunqiu` | 6.0 秒   | 2.4 秒       |
| 资产库页 `/en/kit/tang-yunqiu`  | 5.5 秒   | 2.4 秒       |

数据存在 `.devspace-reports/site-round-2/lighthouse-*-mobile.json`。

- **结果**：在不改变视觉的前提下，档案页和资产库页的手机端速度指数都在 4 秒以内。做不到就写明卡在哪里。
- **验收**：
  - 发布后在正式站对这三页各跑一次 Lighthouse 手机端，存进 `.devspace-reports/site-round-4/`，报告里写前后对比；
  - 性能、无障碍、SEO 三项分数都不能比第二轮低。

## 3. 安全检查

- 跑 `pnpm audit --registry https://registry.npmjs.org`（镜像源没有 audit 接口）。
- 只处理 high 和 critical：能用补丁版本解决的就升级，`pnpm verify` 全过才保留。
- 没有 high 或 critical，就什么都不升，在报告里写"已检查，无需升级"。
- 试运营期不做普通的版本升级。

## 4. 怎么判断

| 闸门 | 命令                             | 第三轮基线                       | 底线               |
| ---- | -------------------------------- | -------------------------------- | ------------------ |
| 完整 | `pnpm verify`                    | 工具测试 40、Playwright 54，全绿 | 全绿，数量只升不降 |
| 文档 | `pnpm docs:check`                | 0 warning                        | 0 warning          |
| 组件 | `pnpm exec swimmer-ui-check src` | 通过                             | 通过               |

不许为了变绿去加大超时、放松断言、跳过测试。
