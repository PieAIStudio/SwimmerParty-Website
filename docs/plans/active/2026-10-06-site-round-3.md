## 1. 要修的

1. **canonical 少了语言前缀**：`src/i18n/metadata.ts` 的 `localizedAlternates(path)` 把 canonical 设成 `path`，
   于是 `/zh/actors/tang-yunqiu` 的 canonical 是 `/actors/tang-yunqiu`、`/en/works` 是 `/works`、首页是根域名，三者都会再跳转。
   第二轮 Lighthouse 已经把首页 canonical 判 0 分（`.devspace-reports/site-round-2/lighthouse-mobile.json`）。
   修复：canonical = 当前页自己的完整网址（含 `/${locale}`）；测试改成比对**带语言前缀的绝对网址**，不能只比路径。
   验收：sitemap 每个网址的 canonical 等于它自己；Lighthouse 首页 SEO 的 canonical 项通过。
2. **演员分享卡片被旧图盖掉**：`src/app/[locale]/actors/[slug]/page.tsx` 的 `generateMetadata` 手动把 `openGraph.images`
   设成透明底的 `turnaround.front.webp`，覆盖了同目录 `opengraph-image.tsx` 生成的卡片（`twitter:image` 同样）。
   删掉手动指定，让演员页、资产库页都用生成的 1200×630 卡片。验收：正式站演员页的 `og:image`、`twitter:image` 指向卡片路由且返回 image/png。
3. **联系邮箱收不了信**：合作页显示 `swimmerparty@swiminai.com`，但还没有收件箱，访客来信会退回。
   先查 `swiminai.com` 的 DNS 托管在哪里，再问 Owner 两件事：转发到哪个真实邮箱；同意用哪种转发服务（例如 DNS 托管方自带的邮件转发）。
   Owner 给了之前，页面上不显示这个地址，改成"联系方式即将开通"之类的诚实说法。设置好后发一封测试信验证能收到，再恢复显示。
4. **首页手机端加载偏慢**：第二轮 Lighthouse 手机端速度指数 7.4 秒（档案 6.0、资产库 5.5）。
   找出原因（首屏两张全身图的尺寸和优先级、中文字体分片、首屏 JS），在不改变视觉的前提下改进；目标首页速度指数 4 秒以内，做不到就写明原因。
   前后各跑一次 Lighthouse 手机端存进报告。
5. **收尾第二轮**：把 `2026-10-05-site-round-2.md` 加简短结论后移到 `completed`；更新 `current-work.md`。
