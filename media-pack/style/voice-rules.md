# 声音规则（SWIMMER PARTY 所有演员）

Claude 2026-10-08 写，依据是第一批 MiniMax 实测，以及 Owner 对本地模型"播音腔"的反馈。

## 要什么样的声音

- **自然口语，不是播音腔。** 要有呼吸和停顿，语速跟着情绪走，可以有语气词。听起来像这个人在说话，不是在朗读。
- **口音是身份的一部分。** 中文演员按籍贯带一点地方口音（重庆、东北、天津……），外国演员说英语时带自己的口音。不要都变成标准普通话或标准美音。
- **年龄、性别和体型对得上。** 七十岁的人要有老人的气息，大块头的声音要厚。
- **同一个人每段都要像同一个人。** 先定参考音，后面所有台词都跟它比。

## 每位演员的声音格位

| 格位 | 内容 | 长度 |
| --- | --- | --- |
| `intro` | 母语自我介绍，也是参考音 | 15–20 秒 |
| `intro-alt` | 第二语言自我介绍：中文演员说英语，外国演员说中文 | 15–20 秒 |
| `chat` | 日常聊天 | 10–20 秒 |
| `happy` | 开心 | 10–15 秒 |
| `angry` | 生气 | 10–15 秒 |
| `sad` | 难过 | 10–20 秒 |
| `role-<造型>` | 穿这个角色时的一句戏里台词 | 10–15 秒 |

台词由 Claude 或 Owner 写，写进 `library/voice/<slug>/lines.json`，执行端不自己编台词。

## 怎么做

1. **设计**：MiniMax 网页版"音色设计"。
   - 描述写年龄、籍贯或口音、音色、性格、语速，最后加一句"自然口语，不是播音腔"；
   - 试听文本用 `intro` 台词；
   - 一次出 3 个候选，Owner 挑一个。
2. **量产**：两条路，结果一样命名。
   - 挑中的声音存进 MiniMax 音色槽，用 speech-2.8-hd 合成，情绪格位要选中文字再加情绪；
   - 或者把参考音交给 MediaFactory 本地克隆。
3. **文件**：原件 WAV（MiniMax 下载选"WAV(无水印)"），命名 `{slug}__voice__{格位}__v{大版本}.wav`。
4. **账号**：必须在 MiniMax 付费会员下生成。免费版生成的音频不能商用。

## 验收（每段都听）

1. 像不像同一个人：和 `intro` 并排听。
2. 自然吗：有没有播音腔、机器腔，停顿是否自然。
3. 情绪对不对：开心要真开心，生气要真生气，不能只是音量变了。
4. 口音对不对：和籍贯、语言设定一致。
5. 干净吗：没有杂音、截断、重复，开头结尾不吞字。
6. 文字对不对：和 `lines.json` 一致，没有多读少读。
