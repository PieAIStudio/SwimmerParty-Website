## 为什么比网站规范多做

网站规范（`docs/specs/active/actor-asset-library.md`）的必交基础包是 21 张：转面 4、脸 3、表情 12+2。可选系列有扩展表情、服装、动作、细节。

多做的部分和理由：

| 新增 | 为什么需要 |
| ---- | ---------- |
| 脸：另一侧 3/4、另一侧正侧、仰头、低头 | 视频模型生成转头、抬头、低头时，最容易换脸。两侧都有参考，脸才稳。人脸并不完全对称，发缝、白发也只在一侧。 |
| 全身：背后两侧 3/4 | 背影和转身镜头的参考。 |
| 细节：后脑、双手 | 发型背面和手，是 AI 视频里最容易出错的两处。 |
| 个人风格造型（每人 8 张） | 档案主图、海报用；演员本人的样子，和角色区分开。 |
| 角色造型（每个角色 8 张） | 拍《东游记》要用；规范里只把服装当作"可选"。 |
