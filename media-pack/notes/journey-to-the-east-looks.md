# 《东游记》角色造型方案

## 设定（Owner 2026-10-05 确认）

- 《东游记》是"戏中戏"：片场在拍一部剧《霸道总裁爱上我的中年女佣》。
- **何姐**（唐韵秋饰）：片场里的中年女演员。她在戏中戏里演**中年女佣**。
- **戴尔**（罗米沙饰）：在戏中戏里演**霸道总裁**。
- **调性**：喜剧，讽刺"霸道总裁爱上我"这类短剧。造型比正常的霸总剧再浮夸一点，一看就好笑。

方案第一版 Owner 认为"差不多"，要求更浮夸、更好玩，由我安排。下面是调整后的版本。

## 何姐 · 戏中戏的中年女佣（浮夸版）

- **发型**：一丝不乱的发髻，发胶喷得发亮，头顶戴一个大号白色蕾丝女佣头饰。
- **长相（最终版，Owner 2026-10-05 选定）**：用"短剧式浓妆"那一版——略长的假睫毛、偏红的口红、两团圆圆的腮红。
  - 中间试过"普通中年妇女、素颜"的版本，Owner 认为太老，不用；
  - 浓妆版里有 3 张头大身短（3/4 侧、背面、鸡毛掸子），已按唐韵秋全身正面的成人比例重画，见 `09-何姐女佣-比例检查-重画后.png`。
- **服装**：
  - 深藏青女佣连衣裙，泡泡袖；
  - 超大的白色蕾丝翻领；
  - 层层荷叶边的白围裙，背后一个超大蝴蝶结；
  - 白袖口，深灰平底鞋。
- **8 张图**：
  1. 全身正面
  2. 全身 3/4 侧
  3. 全身正侧
  4. 全身背面（看得到大蝴蝶结）
  5. 近景：捂嘴娇羞，眼含泪光，短剧女主"心动"脸
  6. 端着银托盘和茶杯，小碎步
  7. 拿着粉色大羽毛掸子，侧头偷听
  8. 片场休息：戏服外裹长款羽绒服，戴着头饰，一手剧本、一手泡着枸杞的保温杯

## 共同要求

- 脸和演员本人一致，在演员原来的对话里出图。
- 服装材质写实、干净。浮夸靠款式和配饰，不靠脏乱。
- 透明背景，不加场景，9:16 竖图。
